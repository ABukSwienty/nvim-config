# Neovim config

My personal Neovim config. Requires Neovim 0.12+; plugins are managed with the built-in `vim.pack` and install on first launch.

## Plugins

- [tokyonight.nvim](https://github.com/folke/tokyonight.nvim) — colorscheme
- [telescope.nvim](https://github.com/nvim-telescope/telescope.nvim) + [plenary.nvim](https://github.com/nvim-lua/plenary.nvim) — fuzzy finder
- [nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter) — syntax highlighting and indentation
- [render-markdown.nvim](https://github.com/MeanderingProgrammer/render-markdown.nvim) — rendered markdown in the buffer
- [blink.cmp](https://github.com/saghen/blink.cmp) + [friendly-snippets](https://github.com/rafamadriz/friendly-snippets) — completion and snippets
- [mini.pairs](https://github.com/nvim-mini/mini.pairs) — auto-close brackets and quotes
- [nvim-ts-autotag](https://github.com/windwp/nvim-ts-autotag) — auto-close and rename HTML/JSX tags
- [nvim-lspconfig](https://github.com/neovim/nvim-lspconfig), [mason.nvim](https://github.com/mason-org/mason.nvim), [mason-lspconfig.nvim](https://github.com/mason-org/mason-lspconfig.nvim) — language servers
- [conform.nvim](https://github.com/stevearc/conform.nvim) — formatting
- [gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim) — git signs, hunks and blame
- [lualine.nvim](https://github.com/nvim-lualine/lualine.nvim) + [nvim-web-devicons](https://github.com/nvim-tree/nvim-web-devicons) — statusline and file icons
- [oil.nvim](https://github.com/stevearc/oil.nvim) + [oil-git-status.nvim](https://github.com/refractalize/oil-git-status.nvim) — file explorer
- [toggleterm.nvim](https://github.com/akinsho/toggleterm.nvim) — terminals
